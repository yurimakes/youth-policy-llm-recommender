# README 소개 이미지

서비스의 목적과 이용 순서를 설명하는 이미지입니다. 공개 앱 화면 자체를 변경하지 않습니다.

| 파일 | 내용 |
|---|---|
| `cover.png` | 서비스 소개 표지 |
| `journey.png` | 실제 앱 화면 네 장과 단계별 이용 안내 |
| `build-images.ps1` | 이미지 재생성용 PowerShell 원본 |
| `basket-illustration.png` | 표지용 AI 생성 장바구니 일러스트. 실제 정책 데이터나 서비스 화면이 아닌 장식 이미지 |

2026-10-14 생성. 외부 자산을 요청하지 않습니다. 표지는 1600×680px, 이용 흐름은 1600×1050px입니다. 표지와 설명에는 Windows의 맑은 고딕을, 앱 캡처에는 원본의 Pretendard를 사용합니다. 글꼴 파일을 추가 배포하지 않습니다.

`journey.png`는 [기존 실제 브라우저 캡처](../screens/README.md)를 프레임에 넣고 보기 영역을 제한한 설명 이미지입니다. 화면 속 문구와 정책을 생성하거나 변경하지 않았습니다. 원본 전체 캡처는 `assets/screens/`에 유지합니다. 화면의 정책·조건·입력은 가상 체험 예시이며 상담 요약 날짜는 원본 캡처 기준입니다.

PNG는 Windows의 System.Drawing으로 오프스크린 렌더링했습니다. 저장소 루트에서 `powershell -File assets/readme/build-images.ps1`을 실행하면 두 이미지를 다시 만들 수 있습니다. README의 이미지 대체 텍스트와 단계별 표에도 같은 설명을 제공합니다.
