# 2026-10-07 서비스 고도화 결정

## 배경

기존 MVP는 정책을 찾으려는 사용자가 자신의 조건과 관심사를 먼저 입력하는 방식이다. 최신 기획은 탐색을 시작하기 어려운 사용자가 일상 카드로 시작하고 관심 이후 필요한 정보를 보완하는 흐름에 집중한다.

## 결정

- 서비스명 **지원장바구니**, 프로젝트 표기 **지원장바구니: 청년정책 AI 에이전트**를 사용한다.
- 원본은 `v0.1-mvp`로 보존하고 `docs/service-redesign`에서 후속 일반 커밋을 만든다. 브랜치명은 작업을 이어가는 동안 유지한다.
- 기획 기준은 `docs/planning/service-redesign-2026-10.md`의 2026-10-07 15:37 팀 공유본이다. 원문을 수정하지 않고 개발 세부 계약은 PROJECT_SPEC에 기록한다.
- 상황/목표 시작 방식은 비교안이다. 목표가 있는 사람만 전제하지 않는다.
- 간편 경로와 선택적 상세 경로를 제공한다. 사실과 선호를 구분하고 질문 중단·복귀·수정을 지원한다.
- React·FastAPI·PostgreSQL 등의 새 구조를 개발할 수 있도록 과거 AGENTS의 Streamlit 전용 제한을 갱신한다.
- 첫 코드 단계는 기존 모델을 활용한 UI/DB/LLM 독립 진행 상태와 조건 표시다. 웹/API·저장·AI는 후속 검증 단위로 연결한다.

## 미정·주의

담당자용 우선 여부, 지원 플랫폼 모델/API, 저장·삭제 기준, 초기 정책 20~30개 목록, 호스팅과 실제 테스트 모집은 미정이다. 청년 20명 실제 테스트 절은 공유본에 보류로 표시돼 있다. 구현 완료, 모집 완료, 배포 완료 또는 효과 입증으로 표현하지 않는다.

첨부 로고 HTML은 `assets/brand/logo-preview.html`에 보존한다. 화면 참고 이미지는 실제 구현 화면이 아니므로 README의 구현 캡처로 사용하지 않는다. 외부 Google Fonts 호출이 포함된 로고 미리보기는 앱 연동 전 폰트 제공·라이선스 정책을 확인한다.
