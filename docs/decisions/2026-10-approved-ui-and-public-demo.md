상황·관심·기초 확인·지원 방향·상세 전환 제안·상세 질문·결과 갱신·장바구니 준비·상담 요약을 이어준다. 기존 3개 화면 결정은 이 범위로 대체한다. 모바일 중심의 흰 바탕, 파란 강조색, 회색 보조 정보와 세로 선택 카드를 사용한다. 원본 ZIP과 화면 이미지는 저장소에 복제하지 않는다.

공개 체험은 정적 HTML/CSS/JavaScript와 합성 정책 6개로 운영한다. 상단과 후보·요약에 가상 데이터임을 표시한다. 실제 FastAPI는 로컬 `/demo`의 같은 화면을 통해 기존 서버 계약과 SQLite를 계속 사용한다. 공개 주소에 Python 서버나 실제 DB를 배포했다고 설명하지 않는다.

실제 제도 6개의 공식 소개·공고를 별도 참고 목록으로 연결하고 확인일·모집 종료·기관 확인 필요를 기록한다. 가상 후보와 실제 제도를 자동 대응시키지 않으며 복합 조건의 정규화나 전체 자격 검증이 끝났다고 주장하지 않는다.

장바구니·준비 완료 표시는 화면 메모리에서만 유지한다. 상담 요약·체크리스트·발급 안내·문의 초안은 직접 입력한 사실과 남은 확인사항을 조합한 문서다. 특정 필수 서류나 지원금·기관 연락처를 만들어 넣지 않는다. 복사는 클립보드, PDF 저장은 브라우저 인쇄 기능을 사용한다. 외부 AI나 자동 연락은 사용하지 않는다.

공개 대상은 사용자가 선택한 심사자·팀원이며 로그인 없이 누구나 링크를 열 수 있다. 실제 운영의 개인정보 처리·서버 영구 저장 설계와는 별도의 제출용 체험이다. main 병합은 변경된 코드의 회귀와 핵심 실제 연동 확인 후 진행하고 원본 태그는 유지한다.
