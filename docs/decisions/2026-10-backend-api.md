# UI 분담과 1차 백엔드 API 결정

- 기준일: 2026-10-07
- 작업 브랜치: feature/intake-api
- 기준: PR #2가 병합된 main d0d86f2

팀원이 데모 UI를 담당한다는 사용자 지시에 따라 화면 구현을 제외하고 백엔드·데이터·AI 연결을 진행한다. 첫 후속 검증 단위는 FastAPI 계약과 기존 진행 로직 연결이다.

대화·진행 영구 저장 정책이 미정이므로 첫 API는 stateless로 제공한다. 클라이언트가 응답 상태를 다음 POST 본문에 보내고 서버는 구조·전환·사실 형식을 검증하며 서버 정책 데이터와 한국 날짜로 조건을 재평가한다. 상태 서명·로그인·답변 사실성 인증을 구현했다고 주장하지 않는다. UI는 병렬 요청 순서를 관리하고 오류 시 기존 state를 보존해야 한다.

기존 SQLite를 읽기 전용으로 재사용한다. 후보 목록·판정·기준일은 클라이언트 입력으로 받지 않는다. 서버에 사용자 답변을 저장하거나 외부 AI로 보내지 않는다. CORS는 명시적 데모 origin만 허용하고 응답은 no-store로 반환한다.

FastAPI·HTTPX 설치가 개발 환경에서 차단되어 실제 HTTP 검증은 남아 있다. 계약·Pydantic 검증을 수행하되 이를 HTTP 실행 성공으로 표시하지 않는다. 다음 통합 전 API 의존성 설치, HTTP 테스트와 전체 회귀, 서버 기동을 확인한다.
