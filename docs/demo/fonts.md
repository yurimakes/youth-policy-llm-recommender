# 데모 글꼴

제목·선택 카드·본문에는 Pretendard를 사용한다. Regular(400), SemiBold(600), ExtraBold(800) WOFF2 원본을 데모와 함께 제공하며 외부 글꼴 CDN을 사용하지 않는다. 브라우저는 가장 가까운 굵기의 실제 글꼴을 선택한다.

출처: [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard). 아래 파일을 수정 없이 포함했다.

| `Pretendard-SemiBold.woff2` | `4c6a32de1acd9d0ae77a6d0426185b0e7725b1d7` |
| `Pretendard-ExtraBold.woff2` | `dcd57e757da59f14265e132196c10a5781f81a79` |

SIL Open Font License 1.1 원문과 저작권 고지는 `demo/Pretendard-OFL.txt`에 포함하며 공개 빌드와 로컬 API도 함께 제공한다. 저장소 코드 전체에 이 글꼴 라이선스를 적용하는 것은 아니다.
